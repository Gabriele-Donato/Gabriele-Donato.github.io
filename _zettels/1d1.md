<div style="background:#1e1e1e; color:#f5f5f5; padding:16px; border-radius:8px; font-family:monospace; overflow-x:auto;">
<pre>
$ gcc -dM -E - &lt; /dev/null | grep __STDC_VERSION__
#define __STDC_VERSION__ 202311L
</pre>
</div>



**Meaning:**
-dM prints all macros for preprocessor.

-E runs only preprocessor.

-< /dev/null is an empty input file to make it work.
