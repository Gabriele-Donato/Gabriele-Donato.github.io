Since ANSI C (C99), automatic casting of float to double is no more allowed for operators, but still present for undefined functions.

The best practice is to keep function definition and declaration separate. Function prototype declaration should stay in an header (.h) file to be included in each code that defines the function.

Function declaration do not require parameter name.

**Example**

```c
// A function declaration without parameter names
// functions.h
int f(int, int, float);


// A function definition using parameter names
// main.c
int f(int x, int y, float z)
{
    // function body
}
```
