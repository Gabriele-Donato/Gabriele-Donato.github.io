--- layout: default --- {%- comment -%} ================================================================================ ZETTELKASTEN — index layout ------------------------------------------------------------------------------ A single page that renders every note in the `zettels` collection as an index card, with a sticky control panel (live search + tag index) beside it. All heavy lifting that CAN happen at build time DOES happen at build time: * the tag index and its per-tag counts, * backlink resolution (who links to this note), * the search haystack, injected as data-* attributes. The browser only ever toggles classes — there is no client-side indexing pass and no external library. NOTE ON `id` ------------ Jekyll's DocumentDrop delegates `id` to Document#id, which returns the document's unique identifier (e.g. "/zettel/atomic-habit-formation"). A front-matter key called `id:` is therefore UNREACHABLE from Liquid — it is shadowed by the drop method. The Zettel number lives in `note_id:` instead. COMPATIBILITY ------------- Uses only filters available in Jekyll 3.9 (what github.io builds with) and Jekyll 4.4 (what your Gemfile pins locally): concat, uniq, sort, where_exp, jsonify, normalize_whitespace, strip_html. ================================================================================ {%- endcomment -%} {%- comment -%} ---------- 1. The note set, newest first ---------- {%- endcomment -%} {%- assign notes = site.zettels | sort: "date" | reverse -%} {%- comment -%} ---------- 2. Tag index ------------------------------------------------- Liquid has no hash type, so the tags are flattened into a delimited string and split back into an array. `uniq` gives the index, and `where_exp` over the flat array gives each tag its frequency. Everything is downcased on the way in, so "Psychology" and "psychology" can never become two separate pills. {%- endcomment -%} {%- assign tag_blob = "" -%} {%- for note in notes -%} {%- if note.tags -%} {%- for t in note.tags -%} {%- assign t_norm = t | downcase | strip -%} {%- if t_norm != "" -%} {%- assign tag_blob = tag_blob | append: t_norm | append: "|" -%} {%- endif -%} {%- endfor -%} {%- endif -%} {%- endfor -%} {%- assign tag_blob = tag_blob | split: "|" -%} {%- assign all_tags = tag_blob | sort | uniq -%} {%- comment -%} Optional lead-in: whatever prose sits in the body of zettelkasten.md is rendered here, in the site's own centred post header style. {%- endcomment -%} {%- if page.title or content != blank %}

{%- for note in notes -%} {%- comment -%} ---------- Backlink resolution (build time) ---------- Scan every other note's `links:` array for a reference to THIS note, matched on either its slug or its Zettel number. The needles are wrapped in the "|" delimiter before the substring test, so that a note whose slug is "habits" is not credited with a backlink from a link that actually points at "atomic-habits". {%- endcomment -%} {%- assign backlink_slugs = "" -%} {%- assign note_slug = note.slug | downcase -%} {%- assign needle_slug = note_slug | prepend: "|" | append: "|" -%} {%- assign needle_id = note.note_id | downcase | prepend: "|" | append: "|" -%} {%- for other in notes -%} {%- if other.slug != note.slug and other.links -%} {%- assign haystack = other.links | join: "|" | downcase | prepend: "|" | append: "|" -%} {%- assign hit = false -%} {%- if haystack contains needle_slug -%}{%- assign hit = true -%}{%- endif -%} {%- if note.note_id and haystack contains needle_id -%}{%- assign hit = true -%}{%- endif -%} {%- if hit -%} {%- assign backlink_slugs = backlink_slugs | append: other.slug | append: " " -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- assign backlink_list = backlink_slugs | split: " " -%} {%- assign backlink_count = backlink_list | size -%} {%- comment -%} ---------- Card text ---------- Front-matter `excerpt:` wins when present (cleanest cards, and it keeps stray LaTeX out of the preview); otherwise the body is stripped down to plain text. {%- endcomment -%} {%- assign card_text = note.excerpt | default: note.content | strip_html | normalize_whitespace | strip -%} {%- assign haystack_text = note.content | strip_html | normalize_whitespace | downcase -%} {%- comment -%} ---------- Post -> zettel provenance ---------- `source_post:` names the post this note was extracted from, by the post's own slug (dateless — see _layouts/zettel.html). {%- endcomment -%} {%- assign source_post = false -%} {%- if note.source_post -%} {%- assign wanted_post = note.source_post | downcase -%} {%- for p in site.posts -%} {%- assign p_slug = p.slug | downcase -%} {%- if p_slug == wanted_post -%} {%- assign source_post = p -%} {%- break -%} {%- endif -%} {%- endfor -%} {%- endif -%}
